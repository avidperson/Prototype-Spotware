Frequently Asked Questions

Common questions across accounts, trading, algorithmic execution, APIs, and the cTrader Store.

How can I reset my password?
Select Forgot password? on the cTrader login screen, enter your cTrader ID email, and follow the reset link. See cTrader ID for more details.
Where can I find my trading history?
Open the History tab inside Trade Watch on any cTrader app to view closed positions, deals, and export statements. Learn more in Trading with cTrader.
Can I use cTrader on mobile?
Yes — cTrader is available on iOS and Android with full charting, order management, and cTID sync across devices. Explore the cTrader Mobile guide.
What is the difference between a broker trading account and a cTrader ID (cTID)?
Your cTrader ID (cTID) is your single sign-on login across the cTrader ecosystem. Broker demo and live accounts link to your cTID so charts, workspaces, and Cloud cBots synchronize across Windows, Mac, Web, and Mobile.
Can I write cBots and indicators in Python as well as C#?
Yes. cTrader Algo supports both C# (.NET) and Python. Follow the Create a cBot in Python guide to build and execute Python strategies.
When should I choose cTrader Algo vs. Open API vs. FIX API vs. MCP Servers?
Use cTrader Algo for strategies and indicators running inside cTrader or Cloud. Use Open API for custom web/mobile apps and dashboards. Use FIX API for low-latency institutional order routing. Use cTrader MCP Servers to connect AI assistants like Claude or Cursor.
How does risk management work when copying strategies in cTrader Copy?
In cTrader Copy, funds allocated to a strategy are segregated into a dedicated copy sub-account using an equity-to-equity copying model. You can set an Equity Stop Loss on each copied strategy to cap maximum drawdown, and add or withdraw funds at any time. See Invest in strategies.
How do I install a product from cTrader Store or publish my own as a seller?
Products acquired in the cTrader Store automatically sync to your cTID and appear in your platform under cBots, Indicators, or Plugins (Use a product). To monetize your own tools, complete vendor verification in the Become a seller guide.
